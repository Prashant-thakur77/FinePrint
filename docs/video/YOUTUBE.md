# Fine Print: YouTube and submission kit

## Title (under 100 characters)

Fine Print: checks a market's rules against past rulings before you buy (Total Recall · Walrus × Tatum)

## Description

On 1 June 2026, YES on "MicroStrategy sells any Bitcoin by May 31, 2026?" went from about 11 cents to 81 on news of a filing, then fell from 53 cents to 0.6 cents in two minutes, the minute a rule clarification was posted on-chain. A 2025 market with the same wording had already been disputed twice and resolved NO.

Fine Print checks a market's rules against past rulings before you buy. It keeps resolved markets, wording patterns, its own rulings and every rule version in Walrus Memory on Sui mainnet, reads rules and minute prices through Tatum's Prediction Market API, reads rule changes and disputes from Polygon through Tatum's RPC gateway, and sells cited rulings to bots over x402 (payments currently on Sui testnet).

What you'll see: the MicroStrategy day replayed on the live trader view, the memory switch (rule text only vs. with case law), a bot paying 0.02 test USDC per ruling and skipping the trade, the architecture, and the evaluation results, including where memory did not help.

Replays use only precedents whose market closed before the replay time.

Live app: https://fineprint.prashantthakur.dev

Sources for the figures quoted from the press: https://defirate.com/news/polymarket-trader-loses-500k-loss-after-rules-change-microstrategy-btc-market/ and https://www.casino.org/news/polymarket-sued-by-traders-claiming-6-5m-scam-over-bitcoin-prediction-market/
